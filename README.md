# プロジェクト紹介：Tanks Development Project

## 1. プロジェクト概要
本プロジェクトは、Unityゲームエンジンを使用して開発された、マルチプレイヤー対戦型アクションゲームです。プレイヤーは戦車を操作し、障害物の配置されたフィールドで他のプレイヤーと対戦します。

単なるゲーム制作にとどまらず、「ネットワーク同期」や「拡張性の高い設計」といった技術要素の実装を目的としています。

## 2. 技術スタック
* **Game Engine:** Unity (Universal Render Pipeline対応)
* **Language:** C#
* **Network Engine:** Photon Unity Networking 2 (PUN2)
* **Version Control:** Git

## 3. プロジェクトのポイント

### ① リアルタイム・マルチプレイヤーの実装
対戦ゲームにおいて最も技術的難易度が高い「ネットワーク同期」を、Photon (PUN2) を用いて実装しています。
* **プレイヤー間の位置同期:** 遅延（ラグ）を感じさせないスムーズな移動同期を実現。
* **ルーム管理システム:** ロビーでの待機、マッチング、ゲーム開始といった一連のオンラインフローを構築。

### ② 実務を意識したコンポーネント設計
ソースコードは、機能ごとに疎結合（依存関係を整理した状態）に設計されており、保守性と拡張性を意識しています。
* **戦車の挙動制御:** 移動、射撃、ダメージ判定などを独立したスクリプトで管理し、新しい種類の戦車や武器を追加しやすい設計にしています。
* **多様な環境への対応:** 砂漠、ジャングル、月面といった異なる環境（バイオーム）をプリセット化し、ステージ拡張が容易な構造を構築。

### ③ ユーザー体験（UX）への配慮
* **動的なHUDシステム:** プレイヤーのHPや所持弾薬、パワーアップ状態をリアルタイムに視認できるUIを実装。
* **マルチデバイス対応:** PC操作だけでなく、モバイル端末での操作を想定したバーチャルジョイスティック等の入力系も組み込んでいます。

## 4. 主な実装機能
* **戦車カスタマイズ:** 性能の異なる複数の戦車バリエーションの実装。
* **パワーアップアイテム:** 攻撃力アップ、スピードアップ、回復などのアイテム取得システム。
* **ギミック要素:** ワープホール（Wormhole）など、ゲーム性を高めるフィールドギミックの実装。
* **エフェクト演出:** 爆発エフェクトや土煙など、パーティクルシステムを用いた視覚効果。

## 5. まとめ
このプロジェクトを通じて、複雑なネットワークプログラムの理解と、Unityにおける効率的な開発プロセスを習得しました。
